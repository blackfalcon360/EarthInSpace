# Earth in Space 🌍

Where is Earth right now? Zoom out step by step — all calculated on the phone (no internet, no permissions).

- **☀️ Solar:** top view of the Solar System with the real positions of the planets today. Earth's path so far this year is drawn in green, with the equinoxes, solstices, perihelion (P) and aphelion (A). Live Earth stats: distance from the Sun, speed, sunlight travel time, kilometres travelled since 1 January, next equinox/solstice. Date slider (±1 year) + −30 d / −1 d / Now / +1 d / +30 d. Tap any planet or the Sun.
- **⭐ Stars:** the Milky Way disk seen from above with the Sun in the centre and 21 well-known stars at their real galactic positions. Zoom from 15 to 1,000 light-years. Tap a star.
- **🌌 Galaxy:** schematic Milky Way with the Sun's place in the Orion Spur, 26,700 light-years from the centre, and its orbit. Zoom in to the Sun's neighbourhood.
- **🔭 Address:** Earth → Moon → Solar System → heliosphere → Oort Cloud → Local Cloud → Local Bubble → Orion Spur → Milky Way → Local Group → Virgo → Laniakea → Observable Universe, with light-crossing times, plus all the speeds you are moving at.
